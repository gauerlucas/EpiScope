# Glossary

| Term | French | Definition |
|---|---|---|
| Analysis set | Jeu d'analyse | Set of values per contact (EI, spike rate…) shown in 3D and on the slices. |
| BEM | BEM | Boundary element head model (scalp, skull, brain), for source imaging. |
| Concordance | Concordance | MDT table crossing anatomo-functional systems and modalities (semiology, EEG, MRI, PET, neuropsychology, SEEG). |
| Contact | Plot | Contact of an SEEG electrode; a pair of neighbouring contacts forms a bipolar derivation. |
| Direct evidence | Évidence directe | Part of a region's plausibility due to the sign itself (not to relay or propagation). |
| EI | EI | Epileptogenicity index (Bartolomei 2008); also cEI (connectivity), PEI (permutation entropy). |
| EImax | EImax | Maximum EI value of each contact over several seizures. |
| Epileptogenic zone | Zone épileptogène | Region necessary and sufficient to generate seizures, whose removal or destruction abolishes them. |
| Fingerprint | Empreinte | Time-frequency signature of the epileptogenic zone (Grinenko 2018). |
| Habitual seizure | Crise habituelle | Seizure representative of the patient's seizures; counts double in the summary. |
| HFO | HFO | High-frequency oscillations: ripples (80–250 Hz), fast ripples (250–500 Hz). |
| Hypothesis (H1–H4) | Hypothèse | Network trajectory: origin, relays, symptomatogenic zones. |
| MDT meeting | Staff | Multidisciplinary epilepsy surgery meeting. |
| Pathway | Parcours | The patient's sequence of stages: record, phase 1, MDT meeting, SEEG, surgery, follow-up. |
| Plausibility | Plausibilité | Score from 0 to 1 of a region's compatibility with the sequence of signs; not a probability of being the epileptogenic zone. |
| Prime (A’) | Prime | Talairach convention: an electrode written with ’ lies in the left hemisphere. |
| Prior | Prior | Sign → region link of the reference database, with its weight and source. |
| Relay | Relais | Region on the most plausible path between two successive symptomatogenic zones. |
| ROI | ROI | Region of interest annotated on the slices (sphere, arrow). |
| Session | Séance | Recording within an exploration (one video-EEG day, for example). |
| Symptomatogenic zone | Zone symptomatogène | Region whose activation produces a sign. |
| Template | Gabarit | Average brain (fsaverage, MNI) used when the patient's anatomy has not been computed. |
| Timeline | Frise | Representation of a seizure's signs as bars on the time axis. |
| VEP atlas | Atlas VEP | Division of the brain into 162 cortical regions and deep structures, designed for epilepsy (*Virtual Epileptic Patient*). |
