# Keyboard shortcuts

## Everywhere {#partout}

| Key | Effect |
|---|---|
| <kbd>F1</kbd> | User manual, at the page for the current screen |
| <kbd>F9</kbd> | Patient list |
| <kbd>F4</kbd> | Patient record |
| <kbd>F7</kbd> | Imaging |
| <kbd>F6</kbd> | MDT meeting |
| <kbd>F2</kbd> | In an MDT meeting: present. Elsewhere: 3D view full screen |
| <kbd>Esc</kbd> | Close a menu or a window, leave a mode |

## Seizure entry {#saisie-dune-crise}

| Key | Effect |
|---|---|
| <kbd>Space</kbd> | Stopwatch mode: start, pause, resume the stopwatch |
| <kbd>Shift</kbd>+<kbd>Space</kbd> | Play the seizure |
| Any letter | Jump to the sign search box |
| <kbd>Enter</kbd> | Add the first suggested sign |
| <kbd>1</kbd> <kbd>2</kbd> <kbd>3</kbd> <kbd>4</kbd> | Side of the next sign: left, right, bilateral, unknown |
| <kbd>←</kbd> <kbd>→</kbd> | Step back or forward by 0.5 s (<kbd>Shift</kbd>: 5 s) |
| <kbd>Delete</kbd> | Remove the selected sign (after confirmation) |
| <kbd>Alt</kbd> while dragging | Timeline: no snapping |

## Recording viewer {#visionneuse-de-traces}

| Key | Effect |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> | Previous or next page (<kbd>Shift</kbd>: one second) |
| <kbd>↑</kbd> <kbd>↓</kbd>, <kbd>+</kbd> <kbd>−</kbd> | Gain (of the selected channels, otherwise all) |
| <kbd>Ctrl</kbd>+wheel | Gain |
| <kbd>Page Up</kbd> <kbd>Page Down</kbd>, wheel | Previous or next channels |
| <kbd>Home</kbd> <kbd>End</kbd> | Start or end of the recording |
| <kbd>O</kbd> | Go to the annotated seizure onset |
| <kbd>Delete</kbd> | Delete the selected marker |
| <kbd>[</kbd> <kbd>]</kbd> | Spikes: previous or next spike in the cluster |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Spikes, sleep: undo the last edit |
| <kbd>W</kbd> <kbd>1</kbd> <kbd>2</kbd> <kbd>3</kbd> <kbd>R</kbd> | Sleep (review): score the epoch and move to the next |

## Imaging slices {#coupes-dimagerie}

| Gesture | Effect |
|---|---|
| Wheel, <kbd>↑</kbd> <kbd>↓</kbd> | Next or previous slice |
| <kbd>Ctrl</kbd>+wheel | Zoom around the crosshair |
| <kbd>Shift</kbd>+drag | Contrast and brightness |
| Right-drag | Pan the image |
| Double-click | Reframe |
| <kbd>←</kbd> <kbd>→</kbd> | Electrode check: neighbouring contact or pair |

## MDT presentation {#presentation-du-staff}

| Key | Effect |
|---|---|
| <kbd>→</kbd> <kbd>←</kbd>, <kbd>Page Down</kbd> <kbd>Page Up</kbd> | Next or previous slide |
| <kbd>Home</kbd> <kbd>End</kbd> | First or last slide |
| <kbd>F</kbd> | Full screen |
| <kbd>N</kbd> | Show or hide the outline |
| <kbd>Esc</kbd> | Leave the presentation |

## This manual {#ce-manuel}

| Key | Effect |
|---|---|
| <kbd>/</kbd> or <kbd>Ctrl</kbd>+<kbd>K</kbd> | Search |
| <kbd>↑</kbd> <kbd>↓</kbd> then <kbd>Enter</kbd> | Choose a result |
| <kbd>Esc</kbd> | Close the search or the enlarged image |
