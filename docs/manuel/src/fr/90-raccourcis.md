# Raccourcis clavier

## Partout

| Touche | Effet |
|---|---|
| <kbd>F1</kbd> | Manuel d'utilisation, à la page de l'écran en cours |
| <kbd>F9</kbd> | Liste des patients |
| <kbd>F4</kbd> | Dossier du patient |
| <kbd>F7</kbd> | Imagerie |
| <kbd>F6</kbd> | Staff |
| <kbd>F2</kbd> | Dans un staff : présenter. Ailleurs : vue 3D en plein écran |
| <kbd>Échap</kbd> | Fermer un menu, une fenêtre, sortir d'un mode |

## Saisie d'une crise

| Touche | Effet |
|---|---|
| <kbd>Espace</kbd> | Mode Chrono : démarrer, mettre en pause, reprendre le chronomètre |
| <kbd>Maj</kbd>+<kbd>Espace</kbd> | Lire la crise |
| Une lettre | Aller dans la recherche des signes |
| <kbd>Entrée</kbd> | Ajouter le premier signe proposé |
| <kbd>1</kbd> <kbd>2</kbd> <kbd>3</kbd> <kbd>4</kbd> | Côté du signe suivant : gauche, droite, bilatéral, inconnu |
| <kbd>←</kbd> <kbd>→</kbd> | Reculer ou avancer de 0,5 s (<kbd>Maj</kbd> : 5 s) |
| <kbd>Suppr</kbd> | Retirer le signe choisi (après confirmation) |
| <kbd>Alt</kbd> en glissant | Frise : sans aimant |

## Visionneuse de tracés

| Touche | Effet |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> | Page précédente ou suivante (<kbd>Maj</kbd> : une seconde) |
| <kbd>↑</kbd> <kbd>↓</kbd>, <kbd>+</kbd> <kbd>−</kbd> | Gain (des voies sélectionnées, sinon de toutes) |
| <kbd>Ctrl</kbd>+molette | Gain |
| <kbd>Page préc.</kbd> <kbd>Page suiv.</kbd>, molette | Voies précédentes ou suivantes |
| <kbd>Début</kbd> <kbd>Fin</kbd> | Début ou fin du tracé |
| <kbd>O</kbd> | Aller au début de crise annoté |
| <kbd>Suppr</kbd> | Effacer la marque choisie |
| <kbd>[</kbd> <kbd>]</kbd> | Pointes : pointe précédente ou suivante du groupe |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Pointes, sommeil : annuler la dernière retouche |
| <kbd>W</kbd> <kbd>1</kbd> <kbd>2</kbd> <kbd>3</kbd> <kbd>R</kbd> | Sommeil (relecture) : coter l'époque et passer à la suivante |

## Coupes d'imagerie

| Geste | Effet |
|---|---|
| Molette, <kbd>↑</kbd> <kbd>↓</kbd> | Coupe suivante ou précédente |
| <kbd>Ctrl</kbd>+molette | Zoom autour du réticule |
| <kbd>Maj</kbd>+glisser | Contraste et luminosité |
| Clic droit glissé | Déplacer l'image |
| Double-clic | Recadrer |
| <kbd>←</kbd> <kbd>→</kbd> | Vérification d'une électrode : plot ou paire voisine |

## Présentation du staff

| Touche | Effet |
|---|---|
| <kbd>→</kbd> <kbd>←</kbd>, <kbd>Page suiv.</kbd> <kbd>Page préc.</kbd> | Diapositive suivante ou précédente |
| <kbd>Début</kbd> <kbd>Fin</kbd> | Première ou dernière diapositive |
| <kbd>F</kbd> | Plein écran |
| <kbd>N</kbd> | Afficher ou masquer le plan |
| <kbd>Échap</kbd> | Quitter la présentation |

## Ce manuel

| Touche | Effet |
|---|---|
| <kbd>/</kbd> ou <kbd>Ctrl</kbd>+<kbd>K</kbd> | Rechercher |
| <kbd>↑</kbd> <kbd>↓</kbd> puis <kbd>Entrée</kbd> | Choisir un résultat |
| <kbd>Échap</kbd> | Fermer la recherche ou l'image agrandie |
